Connect your Google Sheet
Paste the Web app link from your own Google Apps Script deployment. It is stored on this device only, and you do this once per device.
Where does this link come from?
  1. Open your Google Sheet → Extensions → Apps Script.
  2. Paste in GAS.gs and save.
  3. ⚙ Project Settings → Script Properties → add APP_PASSWORD.
  4. Deploy → New deployment → Web app, execute as Me, access Anyone.
  5. Copy the /exec link and paste it above.
